# Portfolio Website

Personal portfolio website for Shahaf Israel, built as a static site with HTML, CSS, and JavaScript.

## Short Description

A single-page portfolio that presents professional experience, selected projects, direct project anchor links, contact details, and downloadable resume access.

## Includes

- About section
- Experience section
- Projects section with:
  - Meet Shahaf - AI Interview Agent
  - EscapeCode - Coding Puzzle Game
  - Facebook Data Collection Automation
- Embedded demo videos
- Direct resume download
- Project anchor links for CV navigation
- Custom cursor and animated visual background

## Project Structure

- `index.html` - main page structure and content
- `styles.css` - site styling and layout
- `script.js` - animations, interactions, custom cursor, and background scene
- `Shahaf_Israel_CV.pdf` - downloadable resume
- `Photo of me.png` - profile image

## Run Locally

No build step is required.

Open `index.html` in a browser.

## Direct Project Links

These anchors can be used directly from a CV or external links:

- `#project-meet-shahaf`
- `#project-escapecode`
- `#project-facebook-data-extractor`

Example:

```text
https://your-domain.com/#project-meet-shahaf
```
